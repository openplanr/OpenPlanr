# Maintainers

OpenPlanr's product home is the
[OpenPlanr organization](https://github.com/openplanr).
**[Asem Abdo](https://github.com/AsemDevs)** is its founder, creator, and primary
maintainer. Original contributors retain their attribution and copyright notices.

The primary maintainer reviews architecture and compatibility changes, approves
releases, and coordinates security reports. `.github/CODEOWNERS` records current
review ownership; it does not by itself configure repository permissions or
branch protection.

Changes to maintainer access, release credentials, repository ownership, or
recovery arrangements require explicit owner authorization. Keep credentials and
recovery procedures in private administration records. Verify an additional
maintainer's access and responsibilities before relying on them for recovery or
release coverage. No additional recovery owner is claimed by this document.

Use repository issues for non-sensitive product questions and the
[security policy](../SECURITY.md) for vulnerabilities. Maintainer availability does
not imply staffed, round-the-clock support.
