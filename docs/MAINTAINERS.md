# Maintainers

OpenPlanr is developed in the [OpenPlanr organization](https://github.com/openplanr).
**[Asem Abdo](https://github.com/AsemDevs)** is its founder and primary maintainer.
Original contributors retain their attribution and copyright notices.

The primary maintainer reviews architecture and compatibility changes, approves
releases (the `npm-release` environment requires that approval), and coordinates
security reports. `.github/CODEOWNERS` records review ownership; repository permissions
and branch protection are configured separately.

Changes to maintainer access, release credentials, or repository ownership require the
owner's explicit authorization. Use [Discussions](https://github.com/openplanr/OpenPlanr/discussions)
for product questions and the [security policy](../SECURITY.md) for vulnerabilities.
Maintainer availability does not imply staffed, round-the-clock support; see
[SUPPORT.md](../SUPPORT.md).
