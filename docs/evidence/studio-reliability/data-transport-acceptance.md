## Canonical representation and fixed bounds

`packages/protocol/src/large-object-limits.mjs` is the dependency-free canonical limit authority; `large-object-contracts.mjs` imports and re-exports it. The CLI receives an exact generated copy, so global commands remain available without the optional pipeline. Frozen historical contracts stay unchanged.

| Bound | Representation and enforcement evidence |
| --- | --- |
| 100 MiB unique HTML | Unique sources, rather than per-view copies; B accepts the exact declared maximum and rejects +1. Repeated inline JSON reconstruction is bounded before allocation and falls back to the shared source representation. |
| 128 MiB decoded resources plus catalog/metadata | Independently bounded codecs, source descriptors and totals; B rejects +1 totals. | 8 MiB expanded catalog | Catalog is a separately compressed last span, with pre-inflate limits; R rejects excessive metadata complexity/accessors. B rejects +1 declared catalog length. |
| 64 KiB manifest | Closed descriptors plus canonical UTF-8 byte check. Valid maximal descriptor shapes fit this budget; arbitrary extra fields and oversized fields reject. |
| 1 MiB encrypted chunk including 16-byte GCM tag | At most 1 MiB minus 16 bytes plaintext per encrypted chunk; 129 chunks cover the full decoded byte budget. B rejects +1 chunk size/count and incorrect total accounting, repeated IVs, noncontiguous indices and missing spans. |

| Room hydration window 128 MiB | Bounded pages; first-envelope response is separately bounded to 8 MiB. H returns explicit authenticated continuation, never a partial final verdict. A completed private append basis enables appending after continuation without cursor-zero history reload. Retained projected semantics are explicitly bounded; service retention remains distinct from a single read window. |

New HTML segment resources begin with the zero-prefixed `openplanr.html-segments.utf8-v1` identifier, followed by a bounded count and tagged length-prefixed literal/reference spans. Literal UTF-8 bytes preserve BOM and control characters; lone surrogates reject consistently with canonical bundle JSON. The reader retains old JSON array segment decoding. Both representations retain exact decoded hashes and independently bounded deflate decoding, including an actual end marker.

An encrypted signed manifest binds opaque workspace/revision identity, epoch, lengths, per-chunk IV/hash and catalog span. Independent resource hashes and AAD bind purpose/object/record, with no cleartext HTML/source digest in the encrypted outer transport. The service receipt echoes exact manifest/operation identity over authenticated TLS; no invented service signing authority is claimed.

`upload-spool.mjs` writes the exact closed preparation and chunks privately and fsyncs before the first mutating request. Recovery checks O_NOFOLLOW, owner/mode, bounded UTF-8 reads, stable file metadata and chunk hashes. Missing custody, unsafe paths and corrupted bytes never trigger a fresh replacement publication. Export/import retains exact operation bytes and does not overwrite existing custody.

## Capacity and provenance

The immutable validation optimization uses private WeakMap/WeakSet provenance only after detached recursive inspection, freezing and complete semantic validation. A caller's frozen object, copied digest or previously valid mutable identity cannot acquire it. Shared subtree proofs retain aggregate text/depth bounds. Every accepted final edit retains reference/digest/domain validation. Public preview/session results remain mutable detached copies; trusted editor chrome shares only engine-certified immutable bundle roots. I/SHA test these boundaries.

Full unchanged Studio capacity targets passed on the documented machine: p95 usable load under 3,000 ms and p95 keyboard/pointer response under 50 ms. Chrome: 389.45 / 28.8 / 15.2 ms; Firefox: 411.70 / 34 / 25 ms; WebKit: 496.12 / 32 / 41 ms (load / keyboard / pointer). `diagram-capacity.json` records every sample, browser version, fixture, viewport and device. These are local measurements, not a universal speed guarantee.
