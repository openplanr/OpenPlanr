# US-058: Create Feature issues linked to Epic project

**Feature:** [FEAT-016](../features/FEAT-016-four-level-hierarchy-push-to-linear.md)

## User Story
**As a** product manager
**I want to** Features to become top-level Issues in the Linear project
**So that** I can track feature progress and assign them to teams in Linear

See [US-058-gherkin.feature](./US-058-gherkin.feature) for detailed Gherkin scenarios.
