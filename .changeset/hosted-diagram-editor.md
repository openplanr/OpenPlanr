Let hosted shells mount the shared diagram editor without forking it. A batch transport sends each save as one idempotent request that is resent exactly after an uncertain outcome, including after a reload, and hosts can supply their own wording, theme, command-bar actions and right-panel tabs. Losing access during a save now shows Access changed instead of a stuck Saving state. The outline draws nesting with guide lines, collapsible containers, tree keyboard navigation and drawn kind icons.
