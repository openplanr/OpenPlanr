An approved design review handoff now stays current when only the design renderer changes, for example after an upgrade. Plan and the studio's Handoff Center agree on this, so you can still assemble the implementation package without approving again. The handoff still goes out of date when the design's sources, `design-spec.md` or review feedback change. Browser verification of the new render is reported separately, as before.
