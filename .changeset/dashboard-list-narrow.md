Fit the dashboard List to tablet and phone widths. Below 1200px the List shows a search box, a Filters button with the number of active filters, and the presets: a menu on tablets, a row of pills on phones. Filters opens a sheet where Status, Type, Priority and Label filters apply as you tap them, with Group by and a button that shows how many items match. Rows drop the checkbox and the header: four columns on tablets, two lines on phones. Tap a group's row to collapse it. Grouped by spec, each spec is now its group's header row instead of appearing twice, and the table no longer sits inside a card.
