The package root's TypeScript declarations no longer type any export as `any`: runtime adapters, provenance events, guided interactions, operating origins, ecosystem sagas, artifact review and live rooms, and `runDesignCommand` now declare their real parameters and results, and `planr-pipeline/dashboard` declares the dashboard server. Every typed export now declares exactly the values its module ships: the root gains `detectPipelineMode`, `assertCurrentShipClosureForLanding` and the context-envelope and ship-context helpers and no longer declares the four `*StoredInvestigation` functions it never exported; `./protocol`, `./operate/runtime-v2`, `./operate/intelligence-router-v2` and `./operate/evidence-v2` are corrected the same way. The root and `./operate` declarations now compile with `skipLibCheck: false`; like `./design-lineage` and `./diagram-owner`, the root now needs `@types/node` for its server, child process and Web Crypto types. Runtime behavior is unchanged.
