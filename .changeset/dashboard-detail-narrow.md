Fit the dashboard Detail page to tablet and phone widths. Below 900px the top bar shows a back button to where you opened it from, the item's ID and Copy link, next to search and the live status. On phones the top bar shows only the back button, the ID and Copy link. Below 1200px the page is one column. On phones the trace becomes a list of rows, criteria drop their IDs, and the next step's command sits in a bar above the navigation with Copy command. The Inspector uses the same one-column layout and keeps Open full page. On the full page, click a trace step or a property chip to select it, press C to copy its command, and double-click or press Enter to open it. The Frontmatter toggle now shows the same focus ring as every other control.
