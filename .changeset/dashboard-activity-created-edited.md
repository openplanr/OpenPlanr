Show both the creation and the latest edit of an item on the dashboard Activity page. An item created on one day and updated on a later day now appears as Created on its created date and as Edited on its updated date, so the counts, the chart and "Busiest specs" include both. An item created and updated on the same day still shows one Created row. An updated date earlier than the created date is ignored, so the item shows as Created on its created date.
