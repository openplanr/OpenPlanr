Add shared Mermaid copy import preview and fidelity-aware export controls to the diagram editor. Authors can inspect source ranges, proposed objects and visual snapshots, acknowledge exact losses, and adopt into a new unsaved diagram; complete bundle, Mermaid copy and quality-gated SVG exports remain distinct. Import into an existing saved diagram is unavailable until atomic source replacement is supported.
