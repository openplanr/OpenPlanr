`/planr:design` now designs on the host's own design canvas when the host can publish one. It says so in one line, notes that the canvas is published to the host's service and private until shared, builds one board per screen with the primary journey interactive, and keeps the board sources in the project. It still writes the ten-section `design-spec.md`, now with the canvas link, so `/planr:plan` works as before. Say "use the local studio instead" to keep the local studio, for example for an encrypted company review. Hosts without a design canvas keep the local studio unchanged.
