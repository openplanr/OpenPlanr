Here's how I'd split it:

1. Build somewhere to keep share links: create a link, look it up, revoke it, and remember when it was made.
2. Let a note's owner create a link for that note.
3. Let anyone with a link read the note's title, body and due date without signing in.
4. Make sure a link can't be used to change or delete the note.
5. Let the owner revoke a link, after which it stops working. This needs step 1.
6. Expire links after 30 days, answering 410 afterwards. This also needs step 1.

Steps 2 to 6 all build on step 1, so start there.
