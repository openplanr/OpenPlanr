# OPERATE-SPEC-007 marketplace work item

Umbrella specification: `SPEC-004`  
Release participant: `openplanr-marketplace@1.7.0`

Marketplace owns the staged ecosystem ledger and resolved compatibility record
for the Protocol v1.3 Operating Board agent-harness architecture.

The coordinated targets are `planr-pipeline@0.36.1`, `openplanr@1.20.0`,
`@openplanr/skills@1.22.0`, and marketplace `1.7.0`. Pipeline `0.36.1`
regenerates every runtime surface from the mandate-only contract. OpenPlanr
retires the collector, role-pack compatibility path, source and file-import
configuration, profile budget/provider tuning, evidence diagnostic and
classification commands, and dispatch overrides. Skills mirrors the generated
mandate-and-citation workflow byte-for-byte.

Protocol remains `1.3.0`. Frozen v1.2 fields remain readable for artifact and
digest compatibility, but they are not executable public controls. Claude Code
is `mandate-capable` because its adapter declares enforced tool isolation;
Codex and Cursor are `unsupported` until their adapters can enforce the same
bounded read-only mandate. No structured-provider fallback is advertised.

The same release announces that CLI-owned structured-provider advisor dispatch
and CLI-side AI planning are deprecated in favor of native runtime harnesses.
Compatibility output remains unavailable while this operation is staged. It is
exposed only after all participant PRs, tags, package integrity, release checks,
and production canaries reconcile in the final marketplace transaction.

Before publication each participant can compensate within its own repository.
After an npm package is public, recovery is forward-fix only.
