# @openplanr/canvas

Shared infinite-canvas engine for camera, input, culling, overview, safe area,
roving focus, and thin React bindings. This pre-release scaffold is private and
not published. The engine and bindings are not implemented yet.

Exports:

- `.`: Framework-free core entry, currently empty.
- `./react`: Thin React bindings entry, currently empty.
- `./testing`: Testing helpers entry, currently empty.
- `./styles.css`: Structural canvas styles and z-order variables.
