# Venn

- Grammar ID: `venn`
- Layout family: `containment`
- Required primitives: `set`
- Allowed primitives: `node`, `relation`, `group`, `set`, `annotation`, `emphasis`
- Directions: `radial`
- Mermaid: `unsupported`
- Excalidraw: `editable`

## Use this grammar

Venn semantic grammar using the containment layout family.

## Readability

Simplified 7; balanced 12; faithful 24; hard split threshold 24. Labels stay within 80 characters, with at most 12 crossings and 6 incoming relations per item.
