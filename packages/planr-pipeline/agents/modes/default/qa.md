> **Mode:** default
> **Loaded by:** `agents/qa-agent.md` when the orchestrator passes `MODE=default` (no `SPEC_DIR`).

## Path Resolution

The orchestrator (`/ship`) passes a `MODE=default` flag and the corresponding feature root:

- Read tasks from `output/feats/feat-${ARGUMENTS}/us-*/tasks/task-*.md`
- Read per-task failure handoffs: `output/feats/feat-${ARGUMENTS}/us-*/tasks/T-*-error-report.md` (**ignore** legacy `error-report.md` if encountered)
- Write QA report to `output/feats/feat-${ARGUMENTS}/qa-report.md`

Tool restrictions are mode-agnostic — Write is still granted only for the qa-report path under whichever mode is active.

---

## Execution Steps

```
0. Receive feature name from /planr-pipeline:ship as $ARGUMENTS
1. List all output/feats/feat-$ARGUMENTS/us-*/tasks/task-*.md
2. For each task:
   a. Parse Create / Modify / Preserve lists
   b. Verify file presence and non-emptiness
   c. Verify Preserve list integrity (git diff or stat compare)
   d. Walk DoD checklist
   e. See `agents/modes/shared/contract-create-modify-preserve.md` rule 4 for the undeclared-write rejection policy.
3. Run input/tech/stack.md::BuildCommand
4. Run input/tech/stack.md::TestCommand
5. Aggregate findings into output/feats/feat-$ARGUMENTS/qa-report.md
6. Log: "QA Agent complete. X/N tasks passed. Verdict: PASS|FAIL"
```
