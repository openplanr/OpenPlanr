# OPERATE-SPEC-008 — Protocol v1.4 and generated runtime assets

Umbrella specification: SPEC-005, Agent-Native Cross-Runtime Operating Board.
Target release: `planr-pipeline@0.37.1` (0.37.0 plus the Protocol v1.4 release-canary correction).

This repository owns Protocol v1.4 schemas, runtime binding, research mandates,
rich advisor response contracts, canonical proposal-draft contracts, the six
role registry, procedures, generated Claude/Codex/Cursor assets, and
conformance. Mandates contain workspace roots and procedures rather than
repository bodies, so native agents investigate on demand without an evidence
pack or repository-size ceiling.

The release certifies Claude Code, Codex, and Cursor. Advisory tool isolation is
valid under runtime-governed assurance; no runtime may fall back to another
vendor. Existing Protocol v1.2/v1.3 readers remain supported.

Verification requires schema/orchestration/docs tests, generated-asset drift
checks, Protocol v1.4 conformance, cross-runtime vendor-leak scans, and a packed
tarball smoke test.
