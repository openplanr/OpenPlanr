# OPERATE-SPEC-008 — Agent-native runtime workflow

- **Umbrella specification:** SPEC-005 in `openplanr/planr-pipeline`
- **Repository:** `openplanr/skills`
- **Target:** `@openplanr/skills` 1.23.0

The standalone `planr-operate` skill is the generated Codex adapter for
Protocol v1.4. A bare invocation initializes when needed, researches the
workspace before questions, executes CEO/CTO/CPO/CMO/COO/Chair procedures,
records rich cited responses through the machine-only harness, presents the
Markdown report and provisional draft paths, and stops at review.

The skill binds the complete cycle to Codex and forbids cross-vendor fallback.
Native subagents are preferred; a sequential Codex fallback remains valid. It
never calls `planr-pipeline` directly, exposes harness commands to users, grants
permissions, approves drafts, accepts findings, applies routes, invokes PLAN or
SHIP, or performs external effects.

The skill and every reference file are byte-identical to the canonical assets
generated by `planr-pipeline@0.37.1`. `npm test` verifies byte parity,
research-first behavior, sticky runtime binding, advisory-isolation support,
machine-lifecycle hiding, and authority boundaries.
