# Return rules

Shared by Spec, Plan, Plan Review, Ship, Operate and Release. Each skill lists its own fields.

- Lead with the outcome: what is ready, prepared or released, then what is partial or blocked.
- Link durable artifacts by purpose. Keep inventories, command output and transcripts in their files.
- Report only checks you ran, with their result. Name each check you could not run and what stays unverified.
- Omit empty fields. Give each open issue its impact and the smallest recovery action.
- The summary is a human view, not a schema. Different wording never calls for a rerun or a correction pass.
- Keep any machine-readable field a skill defines unchanged.
